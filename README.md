# Groq Chat CLI (pystart assignment)

This project is a simple command-line chat application built on top of the Groq
OpenAI-compatible Chat Completions API.

The program continuously accepts user input, sends the input to the Groq API,
and prints the assistant's response until the user types `quit`.

---

## Requirements
- Python 3
- A Groq API key
